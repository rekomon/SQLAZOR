What's new

Your database, with an AI copilot

Ask, chart, run, edit, and validate without leaving the generator — every reply is grounded in the schema you actually connected to.

Ask in plain English

Get schema tours, relationship maps, and finished T‑SQL or LINQ queries. Replies use real Markdown headings, tables, and callouts — not raw text.

Charts from real results

Any result with two or more columns becomes a bar, line, or pie chart in one click — drawn from the rows your query returned, never invented numbers.

Read‑only SQL runner

Run SELECT and WITH statements straight from a reply. Hard limits keep it safe: 200 rows, a 15‑second timeout, and no statements that modify data.

Conversations that persist

Search, pin, rename, and reload saved sessions as local JSON. Export any conversation to Markdown, HTML, JSON, or a ZIP bundle.

Ollama, OpenRouter or DeepSeek

Run against your own Ollama models, OpenRouter's curated free models, or DeepSeek's cloud API. Keys stay in %LOCALAPPDATA%; cloud calls receive schema names, never row data.

Arabic‑first layout

Ask in Arabic and the bubble flips to right‑to‑left — mirrored alignment and readable tables, while SQL and code stay left‑to‑right.

AI edits with diff preview

Attach up to five generated files, describe a targeted change, and review an exact line‑by‑line diff before applying it. Validation re‑runs automatically.

Two‑layer validation

Roslyn catches parse errors in C#, Razor code blocks, JSON, and XML instantly. Deep compile runs dotnet build in a temp copy to catch missing types and wiring.

Saved generation profiles

Capture table selections and options per database, then re‑apply them later — or export the profile and import it on another machine.

Preview before you build

Render the generated docs page in a sandboxed iframe and browse every output file with inline code and a ZIP download.

Regeneration‑safe output

Manifests and diffs keep your manual edits intact when the schema changes and you generate again. Only what changed is rewritten.

AI dashboard insights

Ask the model to propose KPIs and cards for the generated dashboard, accept the ones you like, and they flow straight into the app.

Smart lookups

Foreign keys become searchable pickers automatically. AI or a local distinct scan can turn text and categorical columns into lists — and scanned values never leave your machine.

Search inside every dropdown

Generated forms ship MudAutocomplete for foreign keys, backed by a cached search method — type a letter instead of scrolling a thousand rows.

Readable labels, not raw keys

Lookup pickers display a human name while binding the real key, so generated pages read like the data your users already know.
